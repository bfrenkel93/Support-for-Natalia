# Put the family photo here

Upload the hero photograph to this folder named exactly **`hero.jpg`**
(so the path is `public/hero.jpg`). It will appear in the hero automatically —
the site is already set to look for `/hero.jpg`.

### Easiest way (no coding)
1. Go to the repo on GitHub and switch to the working branch
   (`claude/exciting-mayer-7mqu4l`).
2. Open this **`public`** folder → **Add file → Upload files**.
3. Drag your photo in and rename it to **`hero.jpg`**, then **Commit**.
4. Redeploy on Vercel (it usually redeploys automatically on commit).

Prefer a different name or a hosted link? Set **Hero photo URL** in the admin
dashboard (Edit page text) to whatever path/URL you use — e.g. `/hero.jpg` or a
full `https://…` link.

A large landscape photo (roughly 1600×1000 or bigger) looks best.
